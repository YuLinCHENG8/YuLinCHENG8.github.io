带关节极限的7-DOF冗余机械臂解析逆运动学计算及其在冗余度求解中的应用

Position-Based Kinematics for 7-DoF Serial Manipulators with Global Configuration Control, Joint Limit and Singularity Avoidance

原文摘要翻译

本文提出了一种新颖的解析方法，用于唯一求解七自由度机械臂的逆运动学问题，同时避免关节极限和奇异点。引入了两个辅助参数来处理自运动流形：全局配置（GC）参数，用于指定逆运动学解的分支；以及臂角度（ψ），用于在指定分支内参数化肘部冗余。推导了关节角度与臂角度之间的关系，以将关节极限和奇异点映射到臂角度值。然后，针对指定的目标位姿和全局配置，确定考虑关节极限和奇异点后的可行臂角度区间。提出了一种简单的度量方法，根据可行区间计算肘部位置。当臂角度确定后，即可从基于位置的逆运动学算法中唯一计算出关节角度。所提出的方法不存在使用雅可比矩阵固有的缺点，并且可以在实时控制系统中实现。该新算法是首个基于位置的逆运动学算法，能够同时解决全局和局部流形，并使用冗余解析策略来避免奇异点和关节极限。

创新点

  1. 全局配置（GC）参数引入：首次在位置基逆运动学中系统性引入GC参数（θ₂、θ₄、θ₆的符号），用于唯一指定逆运动学解属于哪个c-bundle（配置流形分支），从根本上解决全局流形的不适定性。相比以往方法，这是首个同时处理全局和局部流形的位置基算法。

  2. 关节角-臂角度解析关系完整推导：系统推导了每个关节角θᵢ作为臂角度ψ的解析函数，并将关节角度按数学形式分为pivot joint（i=1,3,5,7，基于atan2）和hinge joint（i=2,6，基于arccos）两类。在此基础上，定义并解析求解了奇异点附近的avoid interval，从而将关节极限和奇异约束完整映射到冗余圆上的可行臂角度区间。

  3. 基于可行区间交集的冗余解析策略：通过计算每个关节的可行区间Ψᵢ的全局交集Ψ_all，将多关节约束问题简化为单一臂角度参数上的区间选择问题。提出的度量函数通过参数α（控制排斥起始距离）和K（控制排斥强度）实现从区间边界到中心的连续平滑排斥，无需优化循环即可实时运行。

一句话总结

本文提出首个同时解决全局配置流形和肘部自运动流形的基于位置（非速度基）逆运动学算法，通过GC参数和臂角度ψ的解析框架将关节极限和奇异点映射为可行区间，并以微秒级计算性能实现实时冗余解析。

研究问题

问题本质

七自由度（7-DoF）串联机械臂的逆运动学是一个欠定（under-constrained）问题——任务空间通常只指定6个变量（3个位置+3个方向），而关节空间有7个自由度，因此存在无穷多组解。这一不适定性（ill-posedness）可分为两个层次：

  1. 全局不适定性：由多个解分支（c-bundle）引起，影响冗余和非冗余机械臂。不同c-bundle之间的边界是co-regular曲面，跨越这些边界必然经过奇异配置。

  2. 局部不适定性：由额外的自由度（肘部冗余）引起，在同一c-bundle内部的自我运动流形上连续变化。

现有方法的局限

速度基Jacobian方法虽有标准流程，但存在若干固有缺点：计算成本高、难以在速度域内映射关节极限、累积误差导致的不稳定性、需要预先分配笛卡尔轨迹、Jacobian求逆导致的奇异点问题。此前尚无方法能同时解决两个层次的流形并提供完整的关节极限/奇异点避免。

数据与任务定义

适用结构

算法适用于无偏移（non-offset）的 S-R-S（Spherical-Rotational-Spherical）拟人机械臂，即由球形肩部、旋转肘部和球形腕部构成的7-DoF运动链。论文以KUKA LBR iiwa 7 R800为模型。

方法主线

机制流程

第一步：定义自运动参数

引入两个参数来处理自运动流形：

全局配置（GC）：GC = {GC₂, GC₄, GC₆}，其中GC_k = sgn(θ_k)（k∈{2,4,6}），即肩部（θ₂）、肘部（θ₄）和腕部（θ₆）关节角度的符号。每个GC_k ∈ {+1, -1}，因此共有2³=8种可能的全局配置组合，唯一指定逆运动学解属于哪个c-bundle。

臂角度（ψ）：定义为实际SEW（肩-肘-腕）平面与参考SEvW平面之间的夹角，参数化肘部在冗余圆上的位置，取值范围ψ ∈ [-π, π]。

第二步：构建虚拟机械臂与参考平面

为解决参考平面定义中的算法奇异点问题，采用Shimizu等的虚拟机械臂方法并扩展：令虚拟机械臂为6-DoF非冗余副本（θ₃=0），其肘部位置通过6-DoF逆运动学唯一确定。参考平面由虚拟机械臂的肩-虚拟肘-腕平面构成，并将GC参数纳入参考平面的计算中以保证配置一致性。


Figure 2: The real manipulator and virtual manipulator.

第三步：推导关节角-臂角度解析关系

前向运动学通过DH参数求得变换矩阵后，将肩部旋转矩阵₀R₃(θ₁,θ₂,θ₃)和腕部旋转矩阵₄R₇(θ₅,θ₆,θ₇)表达为ψ的正弦和余弦函数。由此解出每个关节角θᵢ作为ψ的函数。关节分为两类：

Pivot joint（i=1,3,5,7）：θᵢ(ψ) = atan2(GC_k·[aₙsinψ + bₙcosψ + cₙ], GC_k·[a_dsinψ + b_dcosψ + c_d])

Hinge joint（i=2,6）：θᵢ(ψ) = GC_k·arccos(a·sinψ + b·cosψ + c)

其中k=2对应i∈{1,2,3}，k=6对应i∈{5,6,7}。

第四步：关节极限和奇异点映射到可行区间

对每个关节i，根据θᵢ(ψ)的解析表达式，通过求反函数ψ(θᵢ)将关节极限[θᵢˡ, θᵢᵘ]映射为臂角度上的对应值。对于奇异点，定义dθᵢ/dψ = 0处的驻点位置，并在奇异性臂角度ψ_sing附近设置avoid interval（宽度由常数ε控制）。

每个关节i得到n_j个可行区间Ψ_{i,j}的并集Ψᵢ = ⋃j Ψ{i,j}。全局可行区间由所有关节可行区间的交集决定：Ψ_all = ⋂ᵢ Ψᵢ。


Figure 4: Example of joint limits and singularity intervals in the elbow redundancy circle.

第五步：冗余解析（臂角度选择）

整体控制方案循环流程为：给定目标位姿₀T_d和GC_d → 计算所有关节的可行区间Ψ_all → 参考平面计算 → 确定新臂角度ψ(t) → 逆运动学计算关节角 → 输出。

臂角度psi(t)的计算使用以下度量函数：假设psi(t-1)在全局可行区间内，通过包含参数K和alpha的度量公式确定新臂角度psi(t)。

该度量的效果是：当臂角度靠近区间边界时，被连续平滑地推向区间中心；靠近中心时排斥力趋近于零。参数α越大则臂角度越倾向于保持在区间中部。

关键实现细节

算法整体分为三个子模块：

  1. 逆运动学子模块：从目标位姿和GC参数、臂角度ψ计算关节角
  2. 区间计算子模块：将关节极限和奇异点映射到冗余圆上的可行区间
  3. 完整算法：在控制循环中依次调用区间计算和逆运动学

关键结果

算法性能

算法在MATLAB和C++（使用Boost和Eigen库）中实现，在随机生成的10000个可行位姿上测试性能。

C++实现性能（在Intel i7-4710MQ 2.5GHz, 16GB RAM上）：

  • 逆运动学子模块：平均2.247us，标准差1.228us，最大32.00us
  • 区间计算子模块：平均10.51us，标准差2.015us，最大37.00us
  • 完整算法：平均12.74us，标准差2.103us，最大43.00us

MATLAB实现性能（同一硬件）：

  • 逆运动学子模块：平均230.3us
  • 区间计算子模块：平均822.3us
  • 完整算法：平均77.65us

这些结果表明完整算法在C++中可在约12.7微秒内完成单次逆运动学计算，完全满足典型1kHz（1000us）控制循环的实时要求。

轨迹示例

机械臂从初始关节角度（度）：theta_c = [-0.4101, -16.4986, -18.1542, -81.6500, 152.6198, 114.4466, 8.1812]^T开始，对应GC=3，臂角度psi=58.5882度。沿z轴平移0.25m的线性轨迹过程中，保持末端执行器方向不变。

实验结果显示：参数alpha控制臂角度开始排斥的”距离阈值”——alpha值越大，臂角度越倾向于保持在区间中部；参数K控制排斥的”强度”——K值越大，臂角度从边界回弹的速度越快。

深度分析

为什么有效

  1. 解析方法的确定性：基于位置（而非速度）的解析解使其具备了Jacobian方法不具备的优势：无累积误差、无Jacobian求逆、无需预分配轨迹。这使得算法在需要连续可预测运动的场景中尤为可靠。

  2. GC参数的理论意义：GC参数将c-bundle的拓扑结构映射为可计算的符号参数。8种GC组合对应逆运动学解空间中的8个不同c-bundle，在轨迹执行过程中固定GC即可保证不发生配置跳变。

  3. 降维思想：通过将7维关节空间约束问题映射为1维臂角度上的区间交集问题，大幅降低了计算复杂度。每个关节的约束可以独立计算，再通过集合运算求交即可获得全局可行解空间。

  4. 度量函数的平滑性：排斥函数在区间内是连续的，臂角度变化也是连续的，保证了关节角度轨迹的平滑性，避免了跳跃或突变。

复杂度与扩展性

  • 时间复杂度：O(1)（解析解，无迭代循环）
  • 空间复杂度：O(1)
  • 可通过调整GC参数在轨迹执行前确定配置，避免运行中的分支切换

与Jacobian基方法的本质区别

特性 位置基方法（本文） 速度基Jacobian方法
计算范式 解析闭式解 数值迭代/微分
累积误差 无 有积分漂移
轨迹预分配 不需要 需要
奇异点处理 显式avoid interval Jacobian伪逆奇异性
单次求解时间 ~12 us (C++) 通常ms级

局限

  1. 结构限制：仅适用于无偏移 S-R-S结构的7-DoF拟人机械臂。真实工业机器人（如KUKA LBR iiwa本身带有肩部偏移）需要额外适配。

  2. 柔顺误差未补偿：算法不补偿机械臂的柔顺（compliance）误差，这在变力载荷场景（如手术机器人）中尤为重要。

  3. 可行区间外的处理：当上一个臂角度不在任何可行区间内时，算法需要将肘部移动到最近的可行区间或无法继续运动。这种情况在轨迹点较稀疏或alpha值过大时可能发生。

  4. 参数的安全裕度：alpha值如果过大，允许机械臂更加靠近关节极限运动，降低了安全裕度。alpha的取值需要根据具体任务调参。
